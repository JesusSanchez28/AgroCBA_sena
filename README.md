# AgroCBA

## Propósito

AgroCBA es una aplicación de consola desarrollada en Python para gestionar los productos de una unidad productiva agropecuaria.

## Institución

SENA - Centro de Biotecnología Agropecuaria.

## Programa

Técnico en Programación de Software.

## Funcionalidades

* Registrar productos.
* Consultar productos.
* Buscar productos por código.
* Actualizar productos.
* Eliminar productos.
* Calcular el valor total del inventario.
* Guardar la información de los productos en un archivo JSON.
* Validar los datos ingresados por el usuario.

## Tecnologías

* Python
* JSON
* Git
* GitHub

## Ejecución

Para ejecutar el programa se debe abrir una terminal en la carpeta del proyecto y ejecutar:

`python main.py`
